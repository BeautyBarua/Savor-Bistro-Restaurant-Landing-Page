# Savor Bistro Restaurant Landing Page

A modern and responsive restaurant landing page created for a fictional fine dining restaurant called **Savor Bistro**. This project focuses on clean layout, elegant branding, high-quality food visuals, and a professional user interface.

## Live Demo

https://beautybarua.github.io/Savor-Bistro-Restaurant-Landing-Page/


## Project Overview

This landing page was designed and developed as a personal portfolio project. It includes a premium restaurant-style layout with a dark hero section, signature dishes, reservation call-to-action, and footer information.

## Features

* Modern restaurant landing page design
* Responsive layout for desktop, tablet, and mobile
* Custom hero section with food photography
* Signature dishes card section
* Reservation call-to-action section
* Professional footer with location, contact, hours, and social links
* Custom logo and AI-generated food images
* Built with clean HTML and CSS

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Google Fonts
* AI-generated images
